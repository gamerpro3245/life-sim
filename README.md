# Уютные дни

2D-симулятор жизни на Godot 4. Версия 1.1.0.

## Сейчас есть
- Персонаж, комната, стены
- Холодильник, кровать, кресло
- Время суток и ночь
- Настроение
- Гостиная, кухня, ванная и двери между ними
- Сохранение и загрузка
- Меню паузы
- Четыре потребности (голод, энергия, развлечение, гигиена), пианино
- Столкновения с мебелью
- Третья комната (ванная) с умывальником
- Книжная полка
- Действия занимают время (еда, сон, пианино, книги)
- Деньги и работа: подработка за столом, еда за деньги
- Стены с рамкой в каждой комнате
- Настройки громкости в главном меню, музыка играет с самого начала
- Цели дня с наградами, прогресс сохраняется
- Сообщение при выполнении цели дня
- Настроение влияет на игру
- Экран обучения при первом запуске
- Спальня и кресло для отдыха

## Настроение
- Отличное (75 и выше): ходишь быстрее, работа приносит на 25% больше
- Хорошее (50-74): всё как обычно
- Плохое (25-49): ходишь медленнее
- Ужасное ( ниже 25): ходишь ещё медленнее

## Управление
- Стрелки или WASD - ходить
- E - использовать предмет
- K - сохранить, L - загрузить
- Esc - меню паузы

## Как запустить
Открыть папку life-sim в Godot 4.7 и нажать F5.
