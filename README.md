# Уютные дни

2D-симулятор жизни на Godot 4.

## Сейчас есть
- Персонаж, комната, стены
- Холодильник и кровать
- Время суток и ночь
- Настроение
- Гостиная, кухня и двери между ними
- Сохранение и загрузка
- Меню паузы
- Три потребности (голод, энергия, развлечение), пианино

## Управление
- Стрелки или WASD - ходить
- E - использовать предмет
- K - сохранить, L - загрузить
- Esc - меню паузы

## Как запустить
Открыть папку life-sim в Godot 4.7 и нажать F5.
